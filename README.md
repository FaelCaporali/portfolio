# Portfólio do Fael Caporali

Site pessoal com herói em 3D: busto do Fael (scan fotogramétrico esculpido e riggado com expressões) percorrendo as etapas da carreira.

- `src/` — site (Vite 7, React 19, TypeScript, React Three Fiber, GSAP, Tailwind 4; `pnpm dev`).
- `3d/` — pipeline do busto e do personagem cartoon (Blender 4.5 headless, MPFB, MediaPipe). Ler `3d/README.md` e `3d/ESTADO.md`.
- `docs/` — roadmap com gates (`ROADMAP.md`), pesquisa, pipeline 3D, entrevista, plano do portfólio.

Repositório privado: contém fotos e material de carreira.
